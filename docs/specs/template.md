# Intent

State the user-visible outcome and non-goals.

# Acceptance criteria

1. **AC-1 — Observable behavior:** Given a concrete precondition, when an
   action occurs, then state the exact result.
2. **AC-2 — Failure behavior:** State the expected safe failure and recovery.

# Constraints

Record security, accessibility, performance, data, and compatibility bounds.

# Verification

Map each criterion to unit, integration, end-to-end, or manual evidence.
